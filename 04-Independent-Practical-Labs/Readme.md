
# 🧪 Independent Practical Labs

## Overview

This section will contain practical cybersecurity exercises that I perform independently to reinforce concepts learned through guided training.

The focus is on applying defensive security concepts and documenting the investigation process.

## Planned Exercises

- Log analysis
- Suspicious login investigation
- Phishing email investigation
- Network traffic analysis
- SIEM detection exercises

## Documentation Standards

Each investigation should include:

1. Objective
2. Lab environment
3. Tools used
4. Steps performed
5. Evidence and observations
6. Analysis
7. Findings
8. Lessons learned
